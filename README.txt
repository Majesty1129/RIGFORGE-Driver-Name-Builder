RIGFORGE Driver Name System v13.2.1

핵심 변경
- [바로 구매하기] 클릭 시 스마트스토어 상품 페이지만 새 탭으로 열림
- 현재 Driver Name Builder 페이지는 절대 이동하지 않음
- 견적번호 자동 복사 유지
- 버튼이 잠시 '복사 완료 · 새 탭 열림'으로 변경
- 팝업 차단 시 현재 페이지로 이동하지 않고 안내만 표시
- 기존 내 견적 내역 / 관리자 / Supabase 기능 유지

버전 표시
- 고객 페이지: CUSTOMER · BUILD v13.2.1
- 관리자 페이지: ADMIN · BUILD v13.2.1
- Supabase 저장값 builder_version: 13.2.1

적용
1. Driver Name Builder GitHub 저장소에 index.html과 admin.html을 함께 교체
2. Nulshock-Bold.otf는 같은 폴더에 유지
3. GitHub Pages 배포 완료 후 Ctrl+F5
4. Supabase SQL 재실행 불필요


[v12.7 변경사항]
- 가로형/세로형 모두 기본 제작 수량 2개
- 수량 버튼은 2개 단위로 증감 (2, 4, 6...)
- 미리보기도 실제 제작 수량만큼 표시
- 가격표의 기본가는 2개 기준으로 유지
- 첫 2개 이후 추가 2개(1세트)마다 해당 기본가에서 1,000원 할인
- 견적번호 형식 DN-YYMMDD-XXXX 유지
- 견적 저장 후 Formspree로 관리자 텍스트 메일 알림 전송
- 관리자 SVG 파일명: 단일 옵션 DN-YYMMDD-XXXX.svg / 복수 옵션 DN-YYMMDD-XXXX_01.svg 형식

[v12.7]
- 구매자 화면의 폰트 상태 및 폰트명 안내 영역을 제거했습니다.
- 폰트는 기존처럼 백그라운드에서 자동 로드됩니다.


[v12.7 변경사항]
- 가로형 미리보기에서 글자 폭에 따라 축척이 달라져도 1 SET(2개) 전체 그룹이 항상 세로 중앙에 유지됩니다.
- 화면 우측 상단, 문서 제목, 저장 데이터 및 SVG 메타데이터의 빌드 버전을 v12.7로 통일했습니다.


[v13.2.1 변경사항]
- 단일 견적은 2 SET부터 전체 SET당 1,000원 할인됩니다.
- 견적이 2개 이상이면 각 견적이 1 SET부터 SET당 1,000원 할인됩니다.
- 고객/관리자 화면, 저장 데이터, SVG 메타데이터의 빌드 버전을 v13.2.1로 통일했습니다.
